## 次にやる計画：UI を 2 テーマで実装して切り替える

### 背景

- オーナーは A と E のどちらも良くて決めきれず、両方を実装して切り替えることにした
- E はカラーリングを「ろりぽっぷらしいかわいい色」をメインに変え、パネルやボタンの形はスタイリッシュのまま残す。これを **E+ かわいいスタイリッシュ** と呼ぶ
- 切り替えは駒の「飴／メンバー」と同じ作りにする：タイトル画面で選ぶ、端末に保存する、`?theme=` でも指定できる

**E の色の変え方**（案。仕上がりは設計書で見てもらう）

| 部分 | 元の E | E+ |
| --- | --- | --- |
| 地 | 白 | 淡いピンク `#fff3f8` に、ピンク寄りの細い格子線 |
| 文字・パネルの濃い色 | 黒 | 濃いプラム `#3b1f35` |
| 押せるもの | 蛍光ピンク | ろりぽっぷピンク `#ff4f9a`、影にピンク系 |
| ストライプ | 原色 | メンバーカラーを少し淡くしたもの |
| 装飾 | 幾何学の線 | 小さなハート・星・「!」をちりばめる |
| 形 | 斜めのパネルとボタン、英字の小見出し、傾けた太い数字、四隅の括弧、ランク文字 | そのまま残す |

### 手順 1：E+ のラフを設計書に足す（先に見てもらう）

- `design/ui-mocks.js` に E+ の 3 画面（タイトル・プレイ中・結果）を追加する
- 設計書の UI の節を「採用：A と E+（切り替え）」に更新する
- ここで一度公開し、オーナーが色の好みを言えるようにしてから、手順 2 以降に進む
  - 色はテーマの CSS 変数に集めるので、後から言われても変数を直すだけで済む

### 手順 2：テーマの仕組み

- **マークアップ**：`index.html` は 1 つにし、両テーマに必要な要素を持たせる
  - 例：ロゴは「英字の小見出し／!!!!!!!（1 文字ずつの span）／落ちものパズル」
  - ボタンは「英字の小見出し（START など）＋日本語」
  - HUD の見出しは日本語と英字の 2 つの span
  - 使わない要素はテーマの CSS で隠す
- **CSS**
  - `css/base.css`：配置と動き
  - `css/themes/candy.css`：`[data-theme="candy"]` の範囲だけに効かせる
  - `css/themes/stylish.css`：`[data-theme="stylish"]` の範囲だけに効かせる
  - 今の `tokens.css`・`game.css`・`ui.css` はこの 3 つへ整理し直す
- **盤面の地の色**：`render.js` が CSS 変数（`--board-bg` `--board-tint`）を読んで描く。テーマを切り替えたら読み直す
- **書体**：Google Fonts（M PLUS Rounded 1c・Dela Gothic One）を `display=swap` で読む
- **切り替え**
  - タイトル画面に「UI：キャンディ／スタイリッシュ」（**T9**）を、T8 と並べて置く
  - 優先順位：`?theme=` → 端末に保存した選択 → `CONFIG.theme.default`（`candy`）
  - `html` の `data-theme` を書き換えるだけで、画面は再読み込みしない
  - T8 の作りが手本になる：`js/main.js` の `skinStore` / `applySkin`

## 作業のコツ

- **ローカル配信**：`python -m http.server 8791 --bind 127.0.0.1 --directory <repo>`
  - ポート 8765 は別のサーバー（duo-album）が使っていることがある。取り違えると別アプリのスクリーンショットになる
- **状態を止める**：`?pos=title|play|combo|fever|rescue|hurry|result`、`?seed=`、`?time=`、`?labels=1`、`?debug=1`、`?bot=1`（自動プレイ）
- **撮影**：`bash ~/.claude/skills/app-spec-flow/scripts/shots.sh <URL> <出力フォルダ> 名前=クエリ ...`（`W=500 H=900` などで大きさ指定）
  - ヘッドレス Chrome の仮想時間では bot の動きが実時間と違う。手触りは実機で確かめる
- **長い置換**：Python のスクリプトをファイルに書いてから実行する
  - bash の heredoc にテンプレートリテラル（`${}` やバッククォート）を含むコードを渡すと、解釈に失敗して何も適用されない
- **CSS の優先順位に注意**：以前、フィーバー中の「!」が `.app.fever-on .hud-bangs i` の指定に負けて、全部点灯して見えた
- **駒の画像の背景**：あみのメンバーカラーは緑なので、Gemini の背景はマゼンタにする（`prepare_piece.py` が自動判定）
- **コミットと push**：オーナーの指示があるときだけ行う
